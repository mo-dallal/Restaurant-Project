# Restaurant Project

This is a simple responsive Restaurant Website project developed using pure **HTML**, **CSS**, and **JavaScript**. The project showcases a restaurant's main web presence with a clean design and basic functionality for users to explore menus, contact information, and other restaurant services.

## 🌐 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📂 Project Structure

```
Restaurant-Project/
│
├── index.html        # Main page of the restaurant website
├── css/              # Folder containing CSS files
├── js/               # Folder containing JavaScript files
├── images/           # Folder containing images used in the project
└── README.md         # Project documentation file
```

## ⚙️ Features

- Fully responsive restaurant website
- Interactive navigation menu
- Smooth scrolling and basic animations
- Attractive design to showcase restaurant branding
- Contact information and location section
- Menu display for restaurant items

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/mo-dallal/Restaurant-Project.git
```

2. Open the `index.html` file directly in your web browser.

No additional installation or setup is required since it's a pure front-end project.
